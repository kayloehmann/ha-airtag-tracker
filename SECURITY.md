# Security Policy

## Supported versions

Security fixes are applied to the current default branch. Older releases and
historical branches are supported only when explicitly documented in this
repository.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, credentials, tokens, personal data,
or exploit details in a public issue.

For public repositories, use **Security → Report a vulnerability** on GitHub.
For private repositories, contact the repository owner through the established
private project channel. Include the affected component, reproduction steps,
impact, and any suggested mitigation.

Reports are acknowledged and triaged as soon as practical. Please allow time
for investigation and a coordinated fix before public disclosure.
